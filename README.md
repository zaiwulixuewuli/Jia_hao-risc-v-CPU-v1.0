# Jia_hao-risc-v-CPU

以嘉豪之名，我们搭建了第一个简单的单周期 RISC-V CPU。
*In the name of Jia_hao, we have built our first simple single-cycle RISC-V CPU.*

本项目是一个使用 Verilog HDL 编写的简易单核 CPU 核心。
*This project is a simple single-core CPU core written in Verilog HDL.*

该设计实现了 RISC-V RV32I 基础整数指令集（排除系统调用和环境指令，共 37 条指令），适合用于计算机体系结构学习、数字逻辑设计实践以及微处理器研发的入门参考。
*This design implements the RISC-V RV32I base integer instruction set (excluding system calls and environmental instructions, with 37 instructions in total), making it suitable as an introductory reference for learning computer architecture, practicing digital logic design, and developing microprocessors.*

---

## 1. 设计特性 / Design Features

* **核心架构 / Core Architecture**：单核（Single-core）
* **硬件描述语言 / Hardware Description Language**：Verilog HDL
* **指令集架构 / Instruction Set Architecture (ISA)**：RISC-V RV32I 基础整数指令集（共 37 条，不包含系统指令如 `ECALL`、`EBREAK` 及 `FENCE`）
*RISC-V RV32I base integer instruction set (37 instructions in total, excluding system instructions such as `ECALL`, `EBREAK`, and `FENCE`)*

### 支持的指令列表 (37条) / Supported Instructions (37 Instructions)

* **算术与逻辑运算 (R-type / I-type)**: `ADD`, `SUB`, `SLL`, `SLT`, `SLTU`, `XOR`, `SRL`, `SRA`, `OR`, `AND`, `ADDI`, `SLTI`, `SLTIU`, `XORI`, `ORI`, `ANDI`, `SLLI`, `SRLI`, `SRAI`
*Arithmetic & Logic Operations (R-type / I-type)*
* **访存指令 (I-type / S-type)**: `LB`, `LH`, `LW`, `LBU`, `LHU`, `SB`, `SH`, `SW`
*Memory Access Instructions (I-type / S-type)*
* **条件分支 (B-type)**: `BEQ`, `BNE`, `BLT`, `BGE`, `BLTU`, `BGEU`
*Conditional Branches (B-type)*
* **无条件跳转 (J-type / I-type)**: `JAL`, `JALR`
*Unconditional Jumps (J-type / I-type)*
* **高位立即数加载 (U-type)**: `LUI`, `AUIPC`
*Load Upper Immediate (U-type)*

## 3. 模块说明 / Module Descriptions

* **`pc_reg.v` (程序计数器 / Program Counter)**
在时钟信号驱动下更新并锁存当前的指令地址，支持复位初始化，为 ROM 提供读取地址。
*Updates and latches the current instruction address driven by the clock signal, supports reset initialization, and provides the read address for the ROM.*
* **`decoder.v` (译码器 / Decoder)**
对输入的 32 位指令进行译码，产生各模块所需的控制信号，并负责从指令中提取并符号扩展各类立即数。
*Decodes the incoming 32-bit instructions, generates control signals required by each module, and is responsible for extracting and sign-extending various immediates from the instructions.*
* **`regfile.v` (寄存器堆 / Register File)**
实现 32 个 32 位通用寄存器。支持双端口异步读、单端口同步写，其中 `x0` 寄存器数值硬编码为 0。
*Implements 32 general-purpose 32-bit registers. It supports dual-port asynchronous reading and single-port synchronous writing, with the `x0` register hardwired to 0.*
* **`alu.v` (算术逻辑单元 / Arithmetic Logic Unit)**
根据译码器产生的运算控制信号，对操作数进行加、减、逻辑运算、移位和比较等操作。
*Performs addition, subtraction, logical operations, shifting, and comparison operations on operands based on the control signals generated by the decoder.*
* **`dmem.v` (数据存储器 / Data Memory)**
模拟数据 RAM，负责执行 Load/Store 访存指令时的数据读取与写入。
*Simulates the data RAM, responsible for reading and writing data when executing Load/Store memory access instructions.*
* **`rom.v` (指令存储器 / Instruction Memory)**
作为只读存储器存放程序的机器码，根据 `pc_reg` 提供的地址输出对应的指令。
*Serves as a read-only memory to store the machine code of the program, outputting corresponding instructions based on the address provided by pc_reg.*
* **`cpu_top.v` (顶层模块 / Top Module)**
完成上述所有子模块的例化与信号互连，构建出完整的单核处理器数据通路。
*Instantiates and interconnects all of the above sub-modules to construct a complete single-core processor data path.*

## 4. 仿真与验证 / Simulation and Verification

本项目支持使用多种主流 EDA 和仿真工具进行编译、仿真和波形抓取。
*This project supports using various mainstream EDA and simulation tools for compilation, simulation, and waveform capture.*

### 推荐工具链 / Recommended Toolchain

* **开源方案 / Open-source Solution**：Icarus Verilog (编译/Compilation) + GTKWave (波形查看/Waveform Viewer)
* **商业或集成方案 / Commercial or Integrated Solutions**：Vivado / ModelSim / Quartus

### 简易仿真步骤（以 Icarus Verilog 为例）/ Simple Simulation Steps (Taking Icarus Verilog as an Example)

在终端中进入项目根目录，运行以下命令：
*Enter the project root directory in the terminal and run the following commands:*

```bash
# 1. 编译所有 RTL 源文件及仿真文件
# Compile all RTL source files and simulation files
iverilog -o cpu_sim rtl/*.v tb/tb_cpu.v

# 2. 运行仿真（通常仿真文件会配置输出 .vcd 波形文件）
# Run the simulation (the simulation file is typically configured to output a .vcd waveform file)
vvp cpu_sim

# 3. 使用 GTKWave 打开波形图观察执行结果
# Open the waveform file with GTKWave to observe execution results
gtkwave wave.vcd

```
